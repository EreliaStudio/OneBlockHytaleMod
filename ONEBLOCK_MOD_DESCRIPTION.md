# OneBlock

OneBlock turns Hytale survival into a progression adventure built around a single block. Break it, collect its reward, and watch it immediately regenerate. Every block can give you the material that grows your base—or a creature you must be ready to face.

## What you will find

- **100 themed expeditions** across Easy, Advanced, Difficult, Hard, and Expert tiers.
- **24 combat dungeons** with escalating enemy waves.
- A large collection of resources, ores, plants, building blocks, animals, monsters, and special rewards.
- Expedition and dungeon crystals, dedicated enchanting workbenches, and Expedition Points.
- A progress HUD that shows the current expedition or dungeon and restores your progress after reconnecting.
- Different OneBlock materials and tool requirements: some can be broken by hand, while others need a pickaxe or axe. Better tools work faster.
- Persistent, owner-scoped progression suitable for solo play and multiplayer servers.

## How it works

Your first OneBlock begins in **Meadow**, where every completed break produces one weighted random reward. Early resources let you build a safe platform and craft a **Crystal Enchanter**. Expedition crystals then temporarily transform the block, changing its appearance, loot pool, required tool, difficulty, and duration.

Finish an expedition to earn Expedition Points and, depending on the destination, a crystal that unlocks another branch of the expedition tree. Some rewards are guaranteed and others are selected randomly, so separate playthroughs can take different routes. When an expedition ends, the OneBlock returns to Meadow until you activate another crystal.

Dungeon crystals start combat encounters instead of normal loot expeditions. Each completed break summons the next wave. Enemies from earlier waves do not need to be defeated before another wave is triggered, so prepare a wide, protected arena and suitable equipment before continuing.

## Playing in a normal world

The mod can run inside an existing world and does not replace that world's terrain generator. Craft a **OneBlock Root Workbench**, then make and place a **OneBlock Root** wherever you want the challenge to begin. The player who places the Root owns its progression.

An owner may place multiple Roots in one world; all Roots belonging to that owner share the same active expedition and progress. Other players can mine the Root, but the owner's progression advances. Use the **Root Extractor** to remove a Root without generating a reward. Removing every Root does not erase saved progress.

For the classic private-island experience, install the companion **OneBlock Islands** mod as well. It creates and protects persistent void islands automatically.

## Getting started

1. Obtain or place a OneBlock Root, or enter an island created by the companion mod.
2. Break the Meadow block and secure the area around it before hostile creatures appear.
3. Craft the Crystal Enchanter from the Fieldcraft menu.
4. Use earned resources and Expedition Points to craft expedition crystals.
5. Activate a crystal and complete its required number of OneBlock rewards.
6. Follow newly unlocked branches, improve your tools and equipment, and prepare for dungeons.

Expedition progress, dungeon progress, and unlocked activities are saved between server restarts. In multiplayer, everyone using the same owner's OneBlock shares the current activity and contributes to the same progress.

## Administrator commands

| Command | Purpose |
|---|---|
| `/oneblock status` | Inspect the accessible OneBlock's current activity and progress. |
| `/oneblock start <expeditionId>` | Start a specific expedition on that OneBlock. |
| `/oneblock stop` | Stop the current activity and return its Roots to Meadow. |

These commands are intended for server administration. Players normally progress by crafting and using crystals.

## Compatibility

This is the core mod and includes its gameplay assets. It does not create void worlds or islands by itself. **OneBlock Islands** depends on this mod and can be installed alongside it for automatic island creation, ownership, access control, and fall protection.
